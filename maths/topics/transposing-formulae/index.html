Mathematical Input Guide

You don't need special mathematical symbols. Just use your ordinary keyboard.

Basic notation

7x
Type: 7x or 7*x
x3
Type: x/3
3x −7 5
Type: (3x-7)/5
5(x −2)
Type: 5(x-2)
−13x +42
Type: -13x+42

Rearranging formulae

Always enter the complete equation, including both sides of the equals sign.

pV = nRT
Type: pV=nRT

For example, if you rearrange the formula above to make T the subject:

T = pV nR
Type: T=pV/(n*R)
h = Hr R
Type: h=H*r/R
C = (F−32) ×5 9
Type: C=(F-32)*5/9
r = 1 − aS
Type: r=1-a/S

Useful rules

  • Use / for fractions.
  • Use brackets around complete numerators and denominators.
  • Use * for multiplication if you prefer.
  • Use - for negative numbers.
  • Use = between the two sides.
  • Use pi or π for pi.
  • Spaces don't matter.
  • Multiplication symbols are optional.

Watch out for these mistakes

Brackets make a difference!
Correct: (3x-7)/5
Be careful: 3x-7/5
These are not the same expression.
Check your negative signs!
Correct: u=v-a*t
Incorrect: u=v+a*t
Remember both sides!
Whatever operation you perform on one side of an equation, you must also perform on the other side.
