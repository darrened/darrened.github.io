Lab 2 - Task

If you are comfortable with the previous task, then lets make things more interesting. Classification isn't just limited to datasets like iris, it can also be used for machine vision, after all, images are just a multi-dementional array of numbers.

In this lab, we will be using the famous 'digits' dataset. This is a series of images that show numbers. We will use these images to try and correctly classify the number in the image

This dataset is perfect for starting machine vision as the images are all ready for us, no additional pre-processing required!

Let's start by getting hold of the dataset. It is actually built in to SK Learn. So to get it, you just need to import it:

from sklearn.datasets import load_digits

Then you can load the dataset as follows:

digits = load_digits()
X, y = digits.data, digits.target

Now your digits are in the variable 'X' and their target classification is in y

If you want to see the first 5 digits, that can be done using MatplotLib:

fig, axes = plt.subplots(1, 5, figsize=(10, 3))
for i, ax in enumerate(axes):
    ax.imshow(digits.images[i], cmap='gray')
    ax.set_title(f"Label: {digits.target[i]}")
    ax.axis('off')
plt.show()
