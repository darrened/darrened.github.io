Lab 1 - Task

In lecture, I introduced you to the concept of fuzzy logic

For the remainder of the lesson, consider the following task (which may or may not have been inspired by an urge to play Mario Kart):

  1. Using an example implementation, found here, as reference - create your own fuzzy logic system with the SKFuzzy library.
    Consider 3 inputs:
    1. Speed
    2. Distance to corner
    3. Corner sharpness
    And one output:
    1. Braking force
    If you wish to keep it simple then you can just consider all values to be on a scale of 0-100.
    If you don't want to think up your own rules then click here for some hints

    Consider:

    1. IF speed is high AND distance is close, THEN braking is high
    2. IF speed is high AND corner is sharp, THEN braking is high
    3. IF speed is medium AND distance is close, THEN braking is medium
    4. IF speed is low, THEN braking is low
    5. IF distance is far AND corner is gentle, THEN braking is low
    6. IF distance is close AND corner is sharp, THEN braking is high
  2. If you have finished early and feel like a challenge then click here, you will find a partial implementation of fuzzy logic using vanilla Python. You simply need to complete this and then try to get it to work with the example system in task 1
