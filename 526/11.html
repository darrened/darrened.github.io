Lab 1 - Task

Up until now, most of the machine learning models you’ve seen have relied on labels. For example, predicting whether a passenger survived the Titanic. These are all examples of supervised learning, the model learning from examples where the correct answer is already known.

This week, we look at unsupervised learning. Here, we give the model data... and that’s it! No labels this time! The goal is for the algorithm to discover structure or patterns on its own.

What Is Unsupervised Learning?

Unsupervised learning is all about finding hidden structure in data. There are two major types you will encounter:

  • Clustering: grouping similar items together
  • Dimensionality Reduction: simplifying data while keeping important patterns

You have already been exposed to some dimensionality reduction with PCA so today we will focus mainly on clustering.

K‑Means Clustering

One of the most widely used clustering algorithms is K‑Means. It tries to split your dataset into K groups, where each group contains items that are similar to each other.

Here is a simple example using the classic Iris dataset (which is actually available through sk_learn itself).

from sklearn.cluster import KMeans
from sklearn.datasets import load_iris
import pandas as pd

# Load the dataset
iris = load_iris()
X = iris.data

# Create a K-Means model with 3 clusters
model = KMeans(n_clusters=3, random_state=42)

model.fit(X)

labels = model.labels_
print(labels)

Note. We never told the model what the "correct" flower species were. It simply looked at the measurements and grouped similar flowers together.

Once you have cluster labels, you can visualise them. Remember, multi-dimension, so here are two features to visualise in 2D:

import matplotlib.pyplot as plt

plt.scatter(X[:, 0], X[:, 1], c=labels)
plt.xlabel("Sepal Length")
plt.ylabel("Sepal Width")
plt.title("K-Means Clustering")
plt.show()

If everything worked, you should see three groups, even though the model was never given any labels.

Combining PCA and K‑Means

A common workflow is to reduce the data first, then cluster it:

# Reduce to 2 dimensions
      pca = PCA(n_components=2)
      X_reduced = pca.fit_transform(X)

      # Cluster the reduced data
      model = KMeans(n_clusters=3, random_state=42)
      model.fit(X_reduced)

      plt.scatter(X_reduced[:, 0], X_reduced[:, 1], c=model.labels_)
      plt.title("PCA + K-Means Clustering")
      plt.show()

This often produces cleaner, more meaningful clusters.

Lab 2 - Task

We now have clustered data? But what now? The real value comes from what you do after the clusters have been formed. Below are some of the most common next steps once you have grouped your data.

Evaluating Your Clusters

Unlike supervised learning, we do not have labels to compare against, so we need different ways to judge whether our clusters make sense.

  • Silhouette Score: Measures how similar each point is to its own cluster compared to other clusters.
  • Inertia: Used in K-Means, lower values generally indicate tighter clusters.
  • Elbow Method: Helps you choose a good number of clusters by plotting inertia against K.
from sklearn.metrics import silhouette_score

score = silhouette_score(X, labels)
print("Silhouette Score:", score)

A higher silhouette score means your clusters are more distinct and meaningful.

Understanding the Clusters

Once you have clusters, the next step is to figure out what they actually represent. This usually involves:

  • Looking at the average values inside each cluster
  • Checking which features differ the most between clusters
  • Giving each cluster a meaningful label such as "Budget Shoppers", "High-Risk Patients", "Frequent Travellers"
import pandas as pd

df = pd.DataFrame(X, columns=iris.feature_names)
df["cluster"] = labels

print(df.groupby("cluster").mean())

This helps you understand the story behind each group.

Using Clusters for Further Analysis

Clusters often lay the ground work for other tasks, such as:

  • Feature Engineering: Adding the cluster label as a new feature for a supervised model.
  • Anomaly Detection: Points far from any cluster centre may be outliers.
  • Segmentation: Grouping customers, patients, or users into meaningful categories.

For example, you might cluster customers first, then build a classifier that predicts which cluster a new customer belongs to.

Visualising Cluster Behaviour

Visualisation is a powerful way to understand what your clusters are doing. You can:

  • Plot clusters in 2D using PCA
  • Use pairplots to compare features
import seaborn as sns

sns.pairplot(df, hue="cluster")

This often reveals patterns you might not have noticed.

Acting on the Clusters

Finally, clustering is often performed with the intention of it leading to real decisions. This depends on sector, but some examples might be:

  • Marketing: Targeting different customer groups with different campaigns.
  • Healthcare: Identifying patient groups with similar risk profiles.
  • Finance: Detecting unusual behaviour that may indicate fraud.
  • Operations: Tailoring services to different user segments.

In other words, clustering helps you understand your data at a deeper level, and that understanding drives better decisions.
