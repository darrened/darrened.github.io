Lab 2 - Task

If you are comfortable with the previous task, then let's take a look at a bigger one!

Click here to view the adult income dataset

Your job is to train a model to predict if somebody is likely to make >$50,000 per year

You'll notice a few categorical features in this dataset! We already looked in to one hot encoding, which will create a lot of additional features. However, if you prefer, here are some other encodings to look in to:

  • Label encoding/Ordinal encoding - Technically label encoding should be used on the target, features should use ordinal encoding. This is reasonable to use for tree based models, but distance based models like KNN may be misled
  • Frequency / Target Encoding - Replace each country with its frequency in the dataset (or mean target value). If you adopt this approach, you should look in to "Target Leakage", "TargetEncoder" and SKLearn pipelines.
  • Grouping Rare Categories - Collapse countries with very few samples into an "Other" category.
  • Drop the Feature - Of course, this is always an option

If you want to look in to something more advanced then there is also "embeddings". These are not naively supported by SKLearn though there may be some work arounds.
