Using a Model

Making use of a model is simple, you've already done it when testing! Take the decision tree below:

# Imports go here

# Load and split the data here 

dt = DecisionTreeClassifier()
dt_model = dt.fit(X_train, y_train)

# Test the model against the test data
dt_pred = dt_model.predict(X_test)

That "predict" method on the last line is us using the trained model to make predictions.

So, going back to the titanic_new dataset. I might want to make a new prediction, such as:

PclassSexAgeSibSpParchFare
21290116.0

All you have to do is put these values in a list, observing the correct order of the dataset, and then you can make a prediction. Note multiple predictions can be made, so this is actually a 2D list:

values = [[2, 1, 29, 0, 1, 16.0]]

From here we can use this list to make a prediction:

dt_pred = dt_model.predict(values)
print(dt_pred)

Output:

[1]

It is worth noting that since we trained the dataset using data from pandas, SKLearn does not appreciate being presented with unlabelled columns. If you receive a warning for this, the fix is simple - present the data as a pandas dataframe:

values = [[2, 1, 29, 0, 1, 16.0]]
new_df = pd.DataFrame(values, columns=["Pclass", "Sex", "Age", "SibSp", "Parch", "Fare"])
dt_pred = dt_model.predict(new_df)
print(dt_pred)

Output:

[1]

Saving and Loading a Model

Now on to the important bit. How do you make it so that you do not have to train the model each time you run the software?
The answer is, you save the trained model to your file system.

We can do this using pickle:

import pickle
# Other imports here

# Load and split the data here 

dt = DecisionTreeClassifier()
dt_model = dt.fit(X_train, y_train)

# Test the model here

with open("titanic_model.pkl", "wb") as file:
    pickle.dump(dt_model, file)

This will save our trained model to the file system.

Now when we want to use the model in our software, we can load it in:

import pickle
import pandas as pd
# SKLearn imports also go here

with open("titanic_model.pkl", "rb") as file:
    t_model = pickle.load(file)

values = [[2, 1, 29, 0, 1, 16.0]]
new_df = pd.DataFrame(values, columns=["Pclass", "Sex", "Age", "SibSp", "Parch", "Fare"])
dt_pred = t_model.predict(new_df)
print(dt_pred)

Lab 2 - Task

In the last session we saved and loaded our model using pickle. That works fine inside Python, but what if we want to use our model in other environments, such as C++, JavaScript, or even deploy it to production with optimized runtimes?
This is where ONNX (Open Neural Network Exchange) comes in.

ONNX is a standard format for machine learning models. It allows us to train in scikit-learn, but then run the model in many different frameworks and languages. It also avoids the security risks of pickle, since ONNX files don’t execute arbitrary Python code when loaded.

To use ONNX, you must first install a few thngs!

pip install onnx onnxruntime skl2onnx

Saving a Model to ONNX

import skl2onnx
from skl2onnx import convert_sklearn
from skl2onnx.common.data_types import FloatTensorType
from sklearn.tree import DecisionTreeClassifier

# Train the model
dt = DecisionTreeClassifier()
dt_model = dt.fit(X_train, y_train)

# Define input type (number of features must match your dataset)
initial_type = [('float_input', FloatTensorType([None, X_train.shape[1]]))]

# Convert to ONNX format
onnx_model = convert_sklearn(dt_model, initial_types=initial_type)

# Save to file
with open("titanic_model.onnx", "wb") as f:
    f.write(onnx_model.SerializeToString())

Loading and Using an ONNX Model

import onnxruntime as rt
import pandas as pd
import numpy as np

# Load the ONNX model
sess = rt.InferenceSession("titanic_model.onnx")

# Prepare input values
values = [[2, 1, 29, 0, 1, 16.0]]
new_df = pd.DataFrame(values, columns=["Pclass", "Sex", "Age", "SibSp", "Parch", "Fare"])

# Run prediction
input_name = sess.get_inputs()[0].name
label_name = sess.get_outputs()[0].name
pred_onx = sess.run([label_name], {input_name: new_df.astype(np.float32).values})[0]

print(pred_onx)

Output:

[1]

While onnx is a little more work than pickle, it is the better choice if you want your model to be portable, secure, and production-ready.

Upon using ONNX your model can be shared across frameworks and languages. This means you could train in scikit-learn, deploy in TensorFlow, PyTorch, or even edge devices. In addition your models runtime will be more optimized for speed and more secure than using pickle.
